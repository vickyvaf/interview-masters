# Supertonic 3 TTS Tester (Web Worker In-Browser)

A pure client-side TypeScript & React test environment for **Supertonic 3 TTS**.

## Features
- **100% In-Browser & Off-Thread**: Uses dedicated Web Worker (`supertonicWorker.ts`) for background processing.
- **No Local Python Server**: Removed local Python device backend requirements.
- **Indonesian Female Voices**: Tuned parameters for Lily, Sarah, Jessica, Olivia, and Emily.
